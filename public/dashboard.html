Setup guide (about 15 minutes, done once by your IT admin or Business Central partner)
  1. Register an app in Microsoft Entra ID (portal.azure.com → App registrations → New registration). Note the Application (client) ID and Directory (tenant) ID.
  2. Allow it to use Business Central: API permissions → Add → Dynamics 365 Business Central → Application permissions → API.ReadWrite.All (read is all this app uses) → Grant admin consent. Then Certificates & secrets → New client secret, and copy the value.
  3. Add the app in Business Central: search Microsoft Entra Applications → New → paste the client ID, set State to Enabled, and add the permission sets D365 READ and D365 BASIC for your company.
  4. Publish the ledger page: search Web Services → New → Object Type Page, Object ID 25 (Customer Ledger Entries), Service Name CustomerLedgerEntries, tick Published.
  5. Enter the details here, click Test connection, then Sync now. Each sync appears in Uploads and becomes the current report.
