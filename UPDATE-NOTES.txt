New: Settings → Database
  - Connect Supabase (PostgreSQL): Project URL, secret (service_role) key, table name,
    Test connection, "Copy this app's data to Supabase and switch",
    "Switch to the data already in Supabase", "Save to Supabase now", "Switch back to local file".
  - Status: storage in use, connection, documents in the app and in Supabase, last save.
  - Setup guide with the SQL to run in Supabase (one private table, row level security on).
  - Backup & restore of all data as a JSON file (never passwords or keys).

On Render, after connecting, add these environment variables (Service → Environment):
  SUPABASE_URL=https://<project>.supabase.co
  SUPABASE_SERVICE_KEY=<secret service_role key>
  DB_BACKEND=supabase
Then every redeploy reloads all data, settings and API keys from Supabase.
